# SAC Global 香港零售渠道上架

這是一個可直接部署到 GitHub Pages 的純靜態繁體中文（香港）網站，介紹品牌產品進入香港四類銷售渠道的評估方向、入貨準備及店內實拍案例。網站沿用 Dropbox Brand 的藍色、黑色及模組化網格視覺語言；所有圖片均為本地相對路徑，沒有外部執行時依賴。

## 啟用 GitHub Pages

1. 將本資料夾內容推送至 GitHub repository 的 `main` branch。
2. 進入 repository **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. 選擇 `main` branch 及 `/ (root)`，按 **Save**。
5. 預期網址：<https://chunmanysac.github.io/retail-listing-hk/>

## 本地檢視

直接以瀏覽器開啟 `index.html` 即可；網站未使用需要建置的框架或套件。
